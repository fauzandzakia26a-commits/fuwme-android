APK Android FUWME dapat diletakkan di folder ini setelah dibuat melalui workflow
"Build FUWME Android APK" pada GitHub Actions. Gunakan nama FUWME.apk agar URL
unduhannya /downloads/FUWME.apk.

Installer Windows (.exe) dapat disimpan di folder ini juga. File APK/EXE belum
disertakan sampai proses build dilakukan.
